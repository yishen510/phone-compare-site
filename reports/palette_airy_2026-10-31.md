# 配色 v6：更透亮、更轻盈

日期：2026-10-31
需求：*提高明度和透明度、降低沉闷感；保持风格协调、文字与元素对比清晰可读；浅色与深色背景都能正常显示。*

---

## 一、把"透亮轻盈"拆成四个可调的旋钮

| 旋钮 | 做法 | 为什么这样才"轻" |
|---|---|---|
| **提高底色明度** | 暗色底 `#0f1319` → `#171d27` | 近黑底会把所有元素压成剪影；抬到中低明度后，层次是靠"亮度差"而不是"黑"来分 |
| **提高玻璃透明度** | L1 不透明 62% → **55%**；L4 90% → 87% | 透出的背景越多，越像"玻璃"而不是"深色板" |
| **提高主色与文字亮度** | accent `#345e95` → `#3b669f`；ink `#c6ceda` → `#dae2ec` | 同一色相上移一档明度，观感立刻轻，但对比度不能因此掉 |
| **减弱"重量"线索** | 背景网格 2.2% → 1.7%；浅色网格 5.5% → 4.5%；遮罩 58% → 50% | 纹理、重遮罩、硬阴影都是"压秤"的东西 |

## 三、可读性怎么证明（不是靠肉眼）

透明化最容易出的问题是"看起来还行，实际对比不够"。所以把自检脚本 `_jst/check_theme.js` 升级成**按玻璃有效面算**：

```
有效面 = blend(glass tint, alpha, --bg)
对比度 = contrast(文字色, 有效面)
```

现在的 22 项全部通过，其中关键几项：

| 检查 | 暗色 | 浅色 |
|---|---|---|
| 正文压卡片面（要求 ≥7） | **11.81** | **15.06** |
| 次要文字压卡片面（≥4.5） | 7.12 | 6.93 |
| 最淡文字压卡片面（≥4.5） | 4.72 | 5.67 |
| 强调字压卡片面（≥4.5） | 9.04 | 8.03 |
| 白字压主按钮（≥4.5） | 5.85 | 7.43 |
| 白字压按钮亮端（≥4.5） | 4.64 | 5.28 |
| 玻璃确实半透明（L1 α ≤0.60） | 0.55 | 0.55 |

对比度全部**不低于**改动前（举例：暗色正文 11.02 → 11.81，最淡文字 3.71 → 4.72），也就是说这轮"提亮提透"没有拿可读性换。

## 四、浅色主题的一个副作用（已修）

底色提到 `#f5f7fb` 后，首屏手机模型的**白色机身融进了近白背景**，看起来像一块悬空的黑屏。

修法：给 `.phone-back` 单独一条浅色定义——冷灰渐变（`#ffffff → #f2f6fc → #e6edf7`）+ 14% 深色描边 + 柔和投影。这样机身仍属"浅色系"，但轮廓回来了。

---

## 五、已知取舍

1. **卡片与背景的明度差变小**：暗色下卡片有效面 `#1e252f` vs 底 `#171d27`，差值比上一版更小。这是"轻盈"的代价——如果想更分明，把 `--glass-1` 的 55% 提到 60%，或把 `--line` 从 8.5% 提到 10%。
2. **浅色主题几乎"全白"**：卡片 `#fbfbfd`、底 `#f5f7fb`，层次主要靠发丝线而不是色差。这是有意为之（轻盈的典型做法），但如果看着"太飘"，把 `--bg` 压到 `#f2f5fa` 即可。
3. **手机模型在暗色下更"灰"**：机身是半透明白渐变，底色提亮后它会跟着变浅，与深色屏幕的对比更强——观感偏冷，但符合"轻盈"方向。
