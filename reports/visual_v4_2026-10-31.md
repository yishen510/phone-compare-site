# 视觉改版 v4：从"发光玻璃"到"精密仪器"

日期：2026-10-31
需求：*风格上更突出科技感，同时保持清雅简洁；避免过度艳丽或繁复；注重克制、留白与整体协调。并说明相比当前版本在科技与清雅平衡上的具体改进点。*

---

## 一、诊断：问题不在颜色，在"表面质感"

前三次调色都没解决问题，因为真正让人不适的不是色相，而是**每一块表面都是半透明 + 模糊 + 内高光**。在深色底上层层叠加，结果是整屏发灰、发雾——像蒙了一层塑料膜，既不"科技"，也不"清雅"。

按行业评价标准的七个维度打分（改版前）：

| 维度 | 判定 | 一句话问题 |
|---|---|---|
| 一致性 | ❌ | `.phone-card` 被定义 3 次、末尾还有一层补丁样式互相覆盖；圆角有 22/16/14/12/999 五种 |
| 层级 | ⚠️ | 卡片、按钮、芯片、筛选栏的"材质"完全一样，只靠颜色区分主次 |
| 可用性 | ✅ | 导航、筛选、对比、快捷键都清晰 |
| 可访问性 | ✅ | 对比度达标、键盘可达 |
| 响应式 | ✅ | 三档屏幕正常 |
| 性能 | ⚠️ | 22 处 `backdrop-filter`，滚动时持续合成开销 |
| 科技感 | ❌ | 靠发光和渐变堆"未来感"，反而像 2010 年的拟物 |

**三个具体毛病**：
1. 首屏有 4 团缓慢漂移的极光（带 `filter:blur(14px)` + 26s 动画），抢 CPU 也抢注意力；
2. 485 张卡每张都挂一个**橙色虚线胶囊**"未通过整机审核"，排下来就是一列橙色噪点；
3. 指针光斑在每次 `mousemove` 都做一次 `getBoundingClientRect`（强制布局）再写两个 CSS 变量。

---

## 二、改造原则

> **科技感来自秩序与精度，不来自发光。**

具体落到三条可执行规则：

1. **表面用实色分层，不用半透明** —— 用三级明度（底 / 卡 / 悬浮）建立深度，而不是靠模糊和阴影。
2. **颜色只在需要时出现** —— 强调色只给主操作、激活态、焦点；状态信息改用 4px 色点 + 中性文字。
3. **形状收敛成一套刻度** —— 圆角 12 / 8 / 7 三级，按钮、输入、芯片共用 8 与 7。

---

## 三、具体改动（改版前 → 改版后）

### 1. 表面：半透明玻璃 → 三级实色

| | 改版前 | 改版后 |
|---|---|---|
| 卡片 | `linear-gradient(rgba(255,255,255,.055→.012))` + `blur(22px)` + 内高光 + 外阴影 | 实色 `#1a2028` + 1px 发丝线 |
| 筛选栏 | 渐变 + `blur(26px) saturate(165%)` + 阴影 | 实色 + 发丝线 |
| 统计卡 | 渐变 + `blur(24px)` + 角部径向光斑 | 实色 + 发丝线（光斑删除） |
| 背景 | 4 团漂移极光 + `blur(14px)` + 26s 动画 | 单层静态径向光，无动画 |

`backdrop-filter` 从 **22 处降到 6 处**，只保留在浮动层（对比坞、弹层、下拉、遮罩）——模糊的作用是"分离层级"，不是给每张卡片做装饰。

### 2. 形状：5 种圆角 → 3 级刻度

`--radius` 22→**12**、`--radius-sm` 14→**9**、`--radius-xs` 10→**7**；按钮从 999 胶囊改为 **8px**，芯片与输入框统一 **7px**。胶囊只留给计数徽标和色点。

副作用修复：卡片圆角变小后，卡片与页面底色的明度差必须补上（`#151a21 → #1a2028`），否则会读成"没画完"。

### 3. 信息色：橙色噪点 → 中性 + 色点

```
改版前：橙色虚线胶囊「未通过整机审核，仅供参考」× 485 张
改版后：发丝线小框 + 4px 琥珀色点 + 灰色小字
```

颜色从"整块底色"退到"一个点"，语义没丢（仍能看出状态），但整屏不再有一列橙色。

### 4. 排版与留白

| | 改版前 | 改版后 |
|---|---|---|
| 首屏标题 | 800 字重、`letter-spacing:-.035em`、62px 上限 | 700 字重、`-.018em`、54px 上限 |
| 标题高亮渐变 | 白→浅蓝→饱和蓝（三色跨度过大） | 近白→雾蓝→灰蓝（降饱和，跨度收窄） |
| 区块标题 | 800 字重、40px | 700 字重、34px |
| 首屏内边距 | 48–96px | **56–112px**（+17%） |
| 区块底部间距 | 56–96px | **72–112px** |
| 卡片内边距 | 20px | 22px |
| 数字 | 比例数字 | `font-variant-numeric: tabular-nums`（金额/统计不再跳动） |
| 卡片参数网格 | 2 列，"充电"被挤成"80W 无 / 线" | 第三项独占一行，不再断词 |

### 5. 一致性清理（这轮改动里"减"最多的部分）

- **合并 `.phone-card` 的三处叠加定义**为一条规则；
- **删除末尾那层冲突补丁**（它把 hover 又改回"上浮 5px + 双重投影"，与新方案打架）；
- **删除指针光斑的死代码**（视觉已移除，JS 仍在每次 `mousemove` 触发强制布局）；
- 净效果：`index.html` **+105 / −151 行**，改版是"减法"。

## 四、科技与清雅的平衡，具体改在哪

**科技感（+）**：
1. 等宽字体承担所有"标注"角色：卡片品牌名 `NUBIA / HONOR`、年份、统计单位、页码式小标——这是"技术文档"的语感，而不是发光。
2. 1px 发丝线取代阴影建立边界，形成类似仪表盘的网格秩序。
3. 8 / 7px 的直角圆角 + 等宽数字，几何上更"精密"；胶囊（完全圆角）只留给计数，形成对比。
4. 保留 `COMPARE / 01`、`SPEC SHEET / 2026` 这类技术标注，但字距与透明度统一，作为"刻度"存在。

**清雅（+）**：
1. 强调色出现面积大幅收缩：首屏从"标题半句 + 主按钮 + 对比徽标 + 状态胶囊"减到**主按钮 + 小徽标**两处。
2. 去掉全部漂移动画与呼吸动画，页面静止——静止感是"清雅"的基础。
3. 留白整体 +17%，卡片与区块之间有了呼吸。
4. 标题字重与字距回收，中文不再被压得发闷。

**两者的交点**：颜色只用来指路（可点、已选中），形状与线条承担结构（在哪、属于谁）——这就是"克制"的具体含义。

## 六、已知取舍（可再调）

1. **卡片 hover 只剩边框变色**，取消了上浮与投影。如果你希望"可点"的暗示更强，把 `translateY(-2px)` 加回去即可，只改一行。
2. **装饰性英文标保留**（`COMPARE / 01` 等）。它们支撑"技术文档感"，但也确实是纯装饰——想更极简可以删掉。
3. **模糊只留在浮动层**。弹层和下拉若也去模糊，会变成"实心方块"，反而更重。
4. 视觉改动未做性能基准：`backdrop-filter` 的成本体现在合成/绘制阶段，不在我现有的 Layout/Script 指标里，所以只能定性说"22 处降到 6 处"，不宣称具体毫秒数。
